# Publication visuals

These English screenshots show the actual native Music Filter 1.0.0 interface in dark mode, with **fictional demonstration data**. The song, artist and album names are invented examples, not a user's exclusion list or listening history.

| Image | Content | Dimensions |
| --- | --- | --- |
| [menu-demo.png](menu-demo.png) | Main menu with the current demo song and the native blue selection. | 576 × 508 px |
| [exclusions-demo.png](exclusions-demo.png) | Exclusions window, showing three recent demo songs and five excluded demo songs in total. | 1240 × 860 px |
| [settings-demo.png](settings-demo.png) | Filtering and launch-with-Music settings. | 600 × 274 px |

The images were captured from an isolated fixture using the unmodified application components. No production Music Filter data, Apple Music playback, account information or desktop background was used. The two menu screenshots were cropped around their native menus to remove the fixture's plain staging window. The interface itself has not been redrawn or generated.

The preview does not run the filtering engine. A checked experimental option in the settings screenshot illustrates the interface, not a completed filtering test.

## Retouched French demonstration illustrations

The following four **AI-retouched promotional illustrations** were prepared from screenshots supplied by the project author. They show the French interface in context with fictional demo names. They are illustrations of the experience, not unmodified screenshots or evidence of a successful live filtering test.

| Image | Content |
| --- | --- |
| [music-filter-menu-contexte-fr-v1.png](music-filter-menu-contexte-fr-v1.png) | Main menu: Blue Hour, Soft Horizons, Aster Vale. |
| [music-filter-reglages-contexte-fr-v1.png](music-filter-reglages-contexte-fr-v1.png) | Main menu and experimental filtering settings. |
| [music-filter-exclusions-contexte-fr-v1.png](music-filter-exclusions-contexte-fr-v1.png) | Three recent demo songs, five excluded demo songs, and export/import menu. |
| [music-filter-recent-contexte-fr-v1.png](music-filter-recent-contexte-fr-v1.png) | Last automatic exclusion: Aster Vale — Blue Hour, with the red indicator. |

Real song and artist names were replaced with fictional examples, the example counts were adjusted, and unrelated menu-bar icons and desktop files were removed. The main-menu illustration was subsequently reframed with the built-in image-generation tool into a 1700 × 925 px landscape canvas, matching the proportions of the paired 1701 × 925 px settings illustration for aligned side-by-side display. The retouching can subtly differ from the native rendering. The original, isolated English interface captures above remain available for comparison. Neither the original personal screenshots nor the user's exclusion list is included in this repository.
